---
title: "Volume discounts"
description: "What volume discounts are and which discounts the API returns."
---

A **volume discount** rewards buying more units. The merchant defines **tiers**, and each tier has a minimum quantity and a discount value:

| Buy | Save |
| --- | --- |
| 2 or more | 5% off each item |
| 3 or more | 10% off each item |
| 5 or more | 15% off each item |

Merchants create volume discounts in Dealeasy. Shopify applies them at checkout. The API gives you the tiers so you can show them on product pages, in quantity selectors, or in carts.

## Which discounts are returned

[`GET /volume-discounts`](/volume-discounts/get-volume-discounts) returns every volume discount that meets all of these conditions:

- It is **active** right now: it has started and has not ended.
- It **applies to the product** you asked about. Merchants can target all products, specific products or variants, collections, or product tags, and can exclude products, collections, or tags.
- It is **available to every customer**. The API has no customer context, so automatic discounts limited to specific customers, segments, or customer tags are left out. Code discounts are always included, because anyone can enter the code.

If nothing matches, you get `200 OK` with `eligible: false` and an empty `volumeDiscounts` array.

<Note>
  Discounts that target specific **variants** only match when you send `variantId`. Send the selected variant whenever you have one.
</Note>

## Multiple discounts

More than one volume discount can apply to the same product. The API returns all of them, **best first**, ranked by the value of the highest tier. If you only show one, use `volumeDiscounts[0]`. That is the one Dealeasy's own storefront widget shows.

## Automatic vs. code discounts

| `method` | What the buyer has to do |
| --- | --- |
| `AUTOMATIC_DISCOUNT` | Nothing. Shopify applies it at checkout once the quantity qualifies. |
| `CODE_DISCOUNT` | Enter `discountCode` at checkout, or you add it to the cart for them. For example, use the Storefront API [`cartDiscountCodesUpdate`](https://shopify.dev/docs/api/storefront/latest/mutations/cartDiscountCodesUpdate) mutation. |

## Out of scope

This API only covers volume discounts. It doesn't return other Dealeasy offer types, and it can't create or update discounts.
