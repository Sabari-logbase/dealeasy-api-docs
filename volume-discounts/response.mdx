## VolumeDiscountResponse

<ResponseField name="eligible" type="boolean" required>
  `true` if at least one volume discount applies to the product. When `false`, `volumeDiscounts` is empty.
</ResponseField>

<ResponseField name="volumeDiscounts" type="VolumeDiscount[]" required>
  The volume discounts that apply, best first. See [which discounts are returned](/volume-discounts/overview#which-discounts-are-returned).

  <Expandable title="VolumeDiscount">
    <ResponseField name="discountId" type="string" required>
      The Shopify discount GID, such as `gid://shopify/DiscountAutomaticNode/…` or `gid://shopify/DiscountCodeNode/…`. It stays the same for the life of the discount.
    </ResponseField>

    <ResponseField name="title" type="string" required>
      The discount title from Shopify. For code discounts it usually matches the code.
    </ResponseField>

    <ResponseField name="method" type="enum<string>" required>
      `AUTOMATIC_DISCOUNT`: Shopify applies it automatically at checkout.
      `CODE_DISCOUNT`: the buyer must enter `discountCode`, or you apply it to the cart.
    </ResponseField>

    <ResponseField name="discountCode" type="string | null" required>
      The code to apply when `method` is `CODE_DISCOUNT`. Always `null` for `AUTOMATIC_DISCOUNT`.
    </ResponseField>

    <ResponseField name="discountType" type="enum<string>" required>
      `PERCENTAGE` or `FIXED_AMOUNT`. Controls how each tier's `value` is read. See [tier values](#tier-values).
    </ResponseField>

    <ResponseField name="fixedQuantityDiscount" type="boolean" required>
      When `false`, a tier applies at its `quantity` **or more**, and the highest qualifying tier wins. When `true`, a tier applies only at **exactly** its `quantity`. Quantities between tiers get no discount.
    </ResponseField>

    <ResponseField name="applicationStrategy" type="enum<string>" required>
      How quantities are counted toward a tier:

      | Value | Quantity counted |
      | --- | --- |
      | `INDIVIDUAL_PRODUCTS` | Per product. 2 × Product A and 1 × Product B count as 2 and 1. |
      | `ALL_PRODUCTS` | Across all qualifying products. 2 × A + 1 × B count as 3. |
      | `INDIVIDUAL_VARIANT` | Per cart line (variant). Each variant is counted on its own. |
    </ResponseField>

    <ResponseField name="currencyCode" type="string | null" required>
      The store's currency (ISO 4217), such as `USD`. `FIXED_AMOUNT` tier values are in this currency.
    </ResponseField>

    <ResponseField name="discountTiers" type="DiscountTier[]" required>
      The tiers, in ascending order of `quantity`.

      <Expandable title="DiscountTier">
        <ResponseField name="id" type="string" required>
          Identifies the tier within this discount: `tier-1`, `tier-2`, … in order. Use it as a UI key. Don't store it, because it changes if the merchant edits the tiers.
        </ResponseField>

        <ResponseField name="quantity" type="integer" required>
          The quantity that unlocks this tier. See `fixedQuantityDiscount`.
        </ResponseField>

        <ResponseField name="value" type="number" required>
          The discount for this tier. What it means depends on `discountType`. See [tier values](#tier-values).
        </ResponseField>

        <ResponseField name="highlight" type="enum<string>" required>
          The badge the merchant chose for this tier:
          `NONE` for no badge, `MOST_POPULAR` for a "Most popular" badge, or `BEST_SAVINGS` for a "Best savings" badge.
          Show it however suits your design.
        </ResponseField>

        <ResponseField name="isDefault" type="boolean" required>
          `true` for the tier to preselect in a quantity selector. At most one tier per discount is `true`, and there may be none. If none is set, preselect the first tier or quantity 1.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Tier values

`value` is always the discount **per item** in the tier:

| `discountType` | `value` means | Example | Price per item on a 20.00 USD product |
| --- | --- | --- | --- |
| `PERCENTAGE` | Percent off each item, from 0 to 100 | `10` | 20.00 − 10% = **18.00** |
| `FIXED_AMOUNT` | Amount off each item, in `currencyCode` | `2.5` | 20.00 − 2.50 = **17.50** |

```javascript Calculating a tier price
function discountedUnitPrice(unitPrice, discount, tier) {
  if (discount.discountType === "PERCENTAGE") {
    return unitPrice * (1 - tier.value / 100);
  }
  return Math.max(0, unitPrice - tier.value); // FIXED_AMOUNT, same currency as unitPrice
}

function activeTier(discount, quantity) {
  const tiers = discount.discountTiers;
  if (discount.fixedQuantityDiscount) {
    return tiers.find((tier) => tier.quantity === quantity) ?? null;
  }
  return tiers.filter((tier) => tier.quantity <= quantity).at(-1) ?? null;
}
```

<Note>
  `FIXED_AMOUNT` values are in the **store's** currency (`currencyCode`). If you show prices in another currency, convert `value` with the same exchange rate you use for product prices. At checkout, Shopify converts the discount to the buyer's currency itself.
</Note>

<Info>
  The values show what Shopify will apply at checkout. The final cart total can still differ, for example when discounts combine with other discounts or when the buyer's cart doesn't match the quantity you assumed. Checkout is always the source of truth.
</Info>
