title: "Get volume discounts"
description: "Get the active volume discounts for a product or variant."
openapi: "GET /volume-discounts"
---

## Parameter formats

| Parameter | Required | Format | Notes |
| --- | --- | --- | --- |
| `productId` | Yes | Numeric ID, such as `8012345678901` | An unknown product returns `INVALID_REQUEST`. |
| `variantId` | No | Numeric ID, such as `44012345678901` | Must belong to `productId`. Needed to match variant-targeted discounts. |
| `country` | No | Two-letter country code, such as `US` | The value of `Shopify.country`. |
| `locale` | No | Language code, such as `en` or `pt-BR` | The value of `Shopify.locale`. |

Send each parameter at most once. Unknown parameters are ignored.

## Where to get the values

In an Online Store theme, every value is already on the page:

| Parameter | Liquid | JavaScript |
| --- | --- | --- |
| `productId` | `{{ product.id }}` | — |
| `variantId` | `{{ product.selected_or_first_available_variant.id }}` | The `variant` URL parameter, after the buyer picks a variant |
| `country` | `{{ localization.country.iso_code }}` | `Shopify.country` |
| `locale` | `{{ request.locale.iso_code }}` | `Shopify.locale` |

The Storefront and Admin GraphQL APIs return IDs as GIDs, such as `gid://shopify/Product/8012345678901`. Send only the number after the last `/`:

```javascript
const toNumericId = (gid) => gid.split("/").pop(); // "gid://shopify/Product/8012345678901" -> "8012345678901"
```

For headless storefronts, which don't have `Shopify.country` or `Shopify.locale`, see the [Shopify headless guide](/guides/shopify-headless#country-and-locale).

## Examples

<CodeGroup>

```bash cURL
curl --get "https://api.dealeasy.app/api/public/v1/volume-discounts" \
  --data-urlencode "productId=8012345678901" \
  --data-urlencode "variantId=44012345678901" \
  --data-urlencode "country=US" \
  --data-urlencode "locale=en" \
  -H "x-dealeasy-api-key: $DEALEASY_API_KEY" \
  -H "x-shopify-domain: your-store.myshopify.com"
```

```javascript JavaScript (fetch)
// Server-side only: never expose DEALEASY_API_KEY to the browser.
const params = new URLSearchParams({
  productId: "8012345678901",
  variantId: "44012345678901",
  country: "US",
  locale: "en",
});

const response = await fetch(
  `https://api.dealeasy.app/api/public/v1/volume-discounts?${params}`,
  {
    headers: {
      "x-dealeasy-api-key": process.env.DEALEASY_API_KEY,
      "x-shopify-domain": "your-store.myshopify.com",
    },
  },
);

const body = await response.json();
if (!response.ok) {
  throw new Error(`Dealeasy API error ${response.status}: ${body.code}`);
}
console.log(body.eligible, body.volumeDiscounts);
```

```javascript Node.js (reusable client)
const DEALEASY_API_URL = "https://api.dealeasy.app/api/public/v1";

export async function getVolumeDiscounts({ shop, productId, variantId, country, locale }) {
  const params = new URLSearchParams({ productId });
  if (variantId) params.set("variantId", variantId);
  if (country) params.set("country", country);
  if (locale) params.set("locale", locale);

  const response = await fetch(`${DEALEASY_API_URL}/volume-discounts?${params}`, {
    headers: {
      "x-dealeasy-api-key": process.env.DEALEASY_API_KEY,
      "x-shopify-domain": shop,
    },
    signal: AbortSignal.timeout(5000),
  });

  const body = await response.json();
  if (!response.ok) {
    const error = new Error(body.message);
    error.code = body.code;
    error.status = response.status;
    throw error;
  }
  return body; // { eligible, volumeDiscounts }
}
```
