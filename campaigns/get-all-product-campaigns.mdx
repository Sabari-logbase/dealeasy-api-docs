---
title: "Get all product campaigns"
description: "Get every active and scheduled product campaign, of every type, with its full rules."
openapi: "GET /campaigns/products"
---

Returns all of the store's product campaigns that are **active or scheduled**, of every supported type. Expired campaigns are never returned. Each campaign includes its `trigger`, `excludes` and `customerEligibility` rules, so you can decide yourself which ones apply.

Use this endpoint to **cache campaigns** and match them yourself, instead of calling the API for every product view. Refresh the cache every few minutes. If you just need what applies to one product, [Get campaigns for a specific product](/campaigns/get-campaigns-for-a-specific-product) is simpler.

<Note>
  The list includes **scheduled** campaigns. Before you show a campaign, check that `startsAt` has passed and that `endsAt` is `null` or in the future.
</Note>

## Response

The response is `{ "campaigns": [...] }`. Each campaign has the [fields every campaign has](/campaigns/overview#fields-every-campaign-has), the [rule fields](/campaigns/overview#rule-fields-get-all-product-campaigns-only), and the fields of its `type`:

| `type` | Structure |
| --- | --- |
| `VOLUME_DISCOUNT` | [Volume discount](/campaigns/volume-discount) |
| `BOGO_DISCOUNT` | [BOGO](/campaigns/bogo) |

Skip campaigns with a `type` you don't support. Use the `type` query parameter to get only one type.

## Examples

<CodeGroup>

```bash cURL
curl "https://api.dealeasy.app/api/public/v1/campaigns/products" \
  -H "x-dealeasy-api-key: $DEALEASY_API_KEY" \
  -H "x-shopify-domain: your-store.myshopify.com"
```

```javascript JavaScript (fetch)
const response = await fetch("https://api.dealeasy.app/api/public/v1/campaigns/products", {
  headers: {
    "x-dealeasy-api-key": process.env.DEALEASY_API_KEY,
    "x-shopify-domain": "your-store.myshopify.com",
  },
});

const body = await response.json();
if (!response.ok) throw new Error(`Dealeasy API error ${response.status}: ${body.code}`);

const volumeDiscounts = body.campaigns.filter((c) => c.type === "VOLUME_DISCOUNT");
const bogos = body.campaigns.filter((c) => c.type === "BOGO_DISCOUNT");
```

```bash cURL (one type)
curl "https://api.dealeasy.app/api/public/v1/campaigns/products?type=BOGO_DISCOUNT" \
  -H "x-dealeasy-api-key: $DEALEASY_API_KEY" \
  -H "x-shopify-domain: your-store.myshopify.com"
```

</CodeGroup>

## Matching campaigns yourself

This endpoint doesn't filter campaigns for a product or buyer. To decide which campaigns apply, build your own logic using the product and customer data you have, together with each campaign's `startsAt`, `endsAt`, `trigger`, `excludes` and `customerEligibility`. Follow the rules in [How a campaign is matched](/campaigns/overview#how-a-campaign-is-matched). IDs in this response are always GIDs.
