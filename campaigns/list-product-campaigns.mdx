---
title: "List product campaigns"
description: "List every active and scheduled product campaign with its full rules."
openapi: "GET /campaigns/products"
---

Returns all of the store's product campaigns that are **active or scheduled**. Expired campaigns are never returned. Each campaign includes its `trigger`, `excludes` and `customerEligibility` rules, so you can decide yourself which ones apply.

Use this endpoint to:

- **Cache campaigns** and match them yourself, instead of calling the API for every product view. Refresh the cache every few minutes.
- **Sync campaigns** to another system, such as a PIM, ERP or search index.

If you just need what applies to one product, [Get specific product campaigns](/campaigns/get-specific-product-campaigns) is simpler.

<Note>
  The list includes **scheduled** campaigns. Before you show a campaign, check that `startsAt` has passed and that `endsAt` is `null` or in the future.
</Note>

## Examples

<CodeGroup>

```bash cURL
curl "https://api.dealeasy.app/api/public/v1/campaigns/products?type=VOLUME_DISCOUNT" \
  -H "x-dealeasy-api-key: $DEALEASY_API_KEY" \
  -H "x-shopify-domain: your-store.myshopify.com"
```

```javascript JavaScript (fetch)
const response = await fetch(
  "https://api.dealeasy.app/api/public/v1/campaigns/products?type=VOLUME_DISCOUNT",
  {
    headers: {
      "x-dealeasy-api-key": process.env.DEALEASY_API_KEY,
      "x-shopify-domain": "your-store.myshopify.com",
    },
  },
);

const body = await response.json();
if (!response.ok) throw new Error(`Dealeasy API error ${response.status}: ${body.code}`);
console.log(body.campaigns);
```

</CodeGroup>

## Matching campaigns yourself

This endpoint doesn't filter campaigns for a product or buyer. To decide which campaigns apply, build your own logic using the product and customer data you have, together with each campaign's `startsAt`, `endsAt`, `trigger`, `excludes` and `customerEligibility`. Follow the rules in [How a campaign is matched](/campaigns/overview#how-a-campaign-is-matched). IDs in this response are always GIDs.

See the [campaign object](/campaigns/campaign-object) for every field.
