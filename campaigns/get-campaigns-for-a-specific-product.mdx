---
title: "Get campaigns for a specific product"
description: "Search for the campaigns that apply right now to a product and buyer."
openapi: "POST /campaigns/products/search"
---

Send the product, its variant, collections and tags, and the buyer in the request body. Dealeasy returns only the **active** campaigns that apply to that product and buyer, of every supported type: scheduled and expired campaigns are never included. It checks each campaign's targeting, exclusions and customer rules against the payload you send. If nothing applies, `campaigns` is an empty array.

<Info>
  This endpoint uses `POST` only because the product and buyer details are sent as a JSON body. It is a read-only search: it never creates or changes a campaign.
</Info>

<Note>
  Dealeasy doesn't look up the product in Shopify. It uses the collections and tags you send. If you leave them out, campaigns that target collections or tags won't match.
</Note>

All of these values are available from Liquid (Online Store) or the Storefront GraphQL API.

<Accordion title="Where to get the values">
  | Field | Liquid (Online Store) | Storefront API |
  | --- | --- | --- |
  | `productId` | `{{ product.id }}` | `product.id` |
  | `variantId` | `{{ product.selected_or_first_available_variant.id }}` | `product.selectedOrFirstAvailableVariant.id` |
  | `collections` | `{{ product.collections \| map: 'id' \| json }}` | `product.collections.nodes[].id` |
  | `tags` | `{{ product.tags \| json }}` | `product.tags` |
  | `customer.id` | `{{ customer.id }}` | Customer Account API `customer.id` |
  | `customer.isB2b` | `{{ customer.b2b? }}` | `true` when the buyer has a company location |
  | `customer.tags` | `{{ customer.tags \| json }}` | Your customer data |
</Accordion>

## Response

The response is `{ "campaigns": [...] }`, **newest first** (latest `startsAt` first). Each campaign has the [fields every campaign has](/campaigns/overview#fields-every-campaign-has) and the fields of its `type`:

| `type` | Structure |
| --- | --- |
| `VOLUME_DISCOUNT` | [Volume discount](/campaigns/volume-discount) |
| `BOGO_DISCOUNT` | [BOGO](/campaigns/bogo) |

The rule fields (`trigger`, `excludes` and `customerEligibility`) are left out, because they have already been applied. Skip campaigns with a `type` you don't support, and decide yourself which campaign to show when several apply.

## Examples

<CodeGroup>

```bash cURL
curl -X POST "https://api.dealeasy.app/api/public/v1/campaigns/products/search" \
  -H "x-dealeasy-api-key: $DEALEASY_API_KEY" \
  -H "x-shopify-domain: your-store.myshopify.com" \
  -H "Content-Type: application/json" \
  -d '{
    "productId": "8012345678901",
    "variantId": "44012345678901",
    "collections": ["411234567890"],
    "tags": ["summer", "cotton"],
    "customer": { "id": "7012345678901", "isB2b": false, "tags": ["vip"] }
  }'
```

```javascript JavaScript (fetch)
const response = await fetch(
  "https://api.dealeasy.app/api/public/v1/campaigns/products/search",
  {
    method: "POST",
    headers: {
      "x-dealeasy-api-key": process.env.DEALEASY_API_KEY,
      "x-shopify-domain": "your-store.myshopify.com",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      productId: "8012345678901",
      variantId: "44012345678901",
      collections: ["411234567890"],
      tags: ["summer", "cotton"],
      customer: { id: "7012345678901", isB2b: false, tags: ["vip"] },
    }),
  },
);

const body = await response.json();
if (!response.ok) throw new Error(`Dealeasy API error ${response.status}: ${body.code}`);

const volumeDiscount = body.campaigns.find((c) => c.type === "VOLUME_DISCOUNT");
const bogo = body.campaigns.find((c) => c.type === "BOGO_DISCOUNT");
```

```javascript Node.js (reusable client)
const DEALEASY_API_URL = "https://api.dealeasy.app/api/public/v1";

export async function getProductCampaigns({ shop, productId, variantId, collections, tags, customer }) {
  const response = await fetch(`${DEALEASY_API_URL}/campaigns/products/search`, {
    method: "POST",
    headers: {
      "x-dealeasy-api-key": process.env.DEALEASY_API_KEY,
      "x-shopify-domain": shop,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ productId, variantId, collections, tags, customer }),
    signal: AbortSignal.timeout(5000),
  });

  const body = await response.json();
  if (!response.ok) {
    const error = new Error(body.message);
    error.code = body.code;
    error.status = response.status;
    throw error;
  }
  return body.campaigns;
}
```
