---
title: "Shopify headless"
description: "Show Dealeasy campaigns in a Hydrogen or Next.js storefront."
---

In a headless storefront, the Dealeasy theme widgets aren't available, so you render campaigns yourself. Shopify still applies them at checkout.

## Prerequisites

- An integration of type `SHOPIFY_HEADLESS` with the `read_campaigns` scope. See [Create an integration](/getting-started/create-an-integration).
- These environment variables:

```bash .env
DEALEASY_API_KEY=dealeasy_xxxxxxxx_xxxxxxxxxxxxxxxx
DEALEASY_SHOP_DOMAIN=your-store.myshopify.com
```

## Steps

<Steps>
  <Step title="Fetch the product with its collections and tags">
    Dealeasy matches campaigns using the data you send, so query the product's `tags` and `collections` from the Storefront API along with the selected variant.
  </Step>
  <Step title="Call Get specific product campaigns">
    POST the product and the buyer to [`/campaigns/products/search`](/campaigns/get-specific-product-campaigns). Storefront API GIDs can be sent as-is.
  </Step>
  <Step title="Render the tiers">
    Use `campaigns[0]`, which is the best one. Show each tier's quantity and discount, and preselect the tier where `isDefault` is `true`.
  </Step>
  <Step title="Let checkout apply it">
    `AUTOMATIC` campaigns apply at checkout by themselves. For `CODE` campaigns, add `code` to the cart.
  </Step>
</Steps>

    ```ts app/lib/dealeasy.server.ts
    const DEALEASY_API_URL = "https://api.dealeasy.app/api/public/v1";

    export type Tier = { id: string; quantity: number; value: number; isDefault: boolean };

    export type Campaign = {
      id: string;
      type: "VOLUME_DISCOUNT";
      title: string;
      method: "AUTOMATIC" | "CODE";
      code: string | null;
      discountType: "PERCENTAGE" | "FIXED_AMOUNT";
      quantityType: "FIXED" | "RANGE";
      quantityScope: "PER_PRODUCT" | "PER_VARIANT" | "ALL_PRODUCTS";
      appliesToSubscriptions: boolean;
      combinesWith: { productDiscounts: boolean; orderDiscounts: boolean; shippingDiscounts: boolean };
      currencyCode: string;
      startsAt: string;
      endsAt: string | null;
      tiers: Tier[];
    };

    export type Buyer = { id?: string; isB2b?: boolean; tags?: string[] };

    export async function getProductCampaigns(
      env: { DEALEASY_API_KEY: string; DEALEASY_SHOP_DOMAIN: string },
      product: { id: string; variantId?: string; collections: string[]; tags: string[] },
      customer?: Buyer,
    ): Promise<Campaign[]> {
      try {
        const response = await fetch(`${DEALEASY_API_URL}/campaigns/products/search`, {
          method: "POST",
          headers: {
            "x-dealeasy-api-key": env.DEALEASY_API_KEY,
            "x-shopify-domain": env.DEALEASY_SHOP_DOMAIN,
            "Content-Type": "application/json",
          },
          body: JSON.stringify({
            productId: product.id,
            variantId: product.variantId,
            collections: product.collections,
            tags: product.tags,
            customer,
          }),
          signal: AbortSignal.timeout(3000),
        });
        const body = await response.json();
        if (!response.ok) {
          console.error(`Dealeasy ${response.status} ${body.code}: ${body.message}`);
          return [];
        }
        return body.campaigns.filter((c: Campaign) => c.type === "VOLUME_DISCOUNT");
      } catch (error) {
        console.error("Dealeasy request failed", error);
        return [];
      }
    }
    ```

    ```tsx app/routes/products.$handle.tsx
    import { useLoaderData } from "react-router";
    import type { Route } from "./+types/products.$handle";
    import { getProductCampaigns } from "~/lib/dealeasy.server";

    export async function loader({ params, context }: Route.LoaderArgs) {
      const { storefront, env } = context;
      const { product } = await storefront.query(PRODUCT_QUERY, {
        variables: { handle: params.handle! },
      });
      if (!product) throw new Response(null, { status: 404 });

      const campaigns = await getProductCampaigns(
        env,
        {
          id: product.id,
          variantId: product.selectedOrFirstAvailableVariant?.id,
          collections: product.collections.nodes.map((c: { id: string }) => c.id),
          tags: product.tags,
        },
        await getBuyer(context), // undefined for guests
      );

      return { product, campaigns };
    }

    // Replace with your own customer lookup (for example, the Customer Account API).
    async function getBuyer(context: Route.LoaderArgs["context"]) {
      if (!(await context.customerAccount.isLoggedIn())) return undefined;
      // return { id: customer.id, isB2b: Boolean(companyLocationId), tags: customerTags };
      return undefined;
    }

    export default function Product() {
      const { product, campaigns } = useLoaderData<typeof loader>();
      const campaign = campaigns[0]; // best campaign first

      return (
        <div>
          <h1>{product.title}</h1>
          {campaign && (
            <ul>
              {campaign.tiers.map((tier) => (
                <li key={tier.id} data-default={tier.isDefault}>
                  Buy {tier.quantity}
                  {campaign.quantityType === "RANGE" ? "+" : ""}, save{" "}
                  {campaign.discountType === "PERCENTAGE"
                    ? `${tier.value}%`
                    : `${tier.value} ${campaign.currencyCode}`}{" "}
                  each
                </li>
              ))}
            </ul>
          )}
        </div>
      );
    }

    const PRODUCT_QUERY = `#graphql
      query Product($handle: String!) {
        product(handle: $handle) {
          id
          title
          tags
          collections(first: 250) { nodes { id } }
          selectedOrFirstAvailableVariant { id }
        }
      }
    `;
    ```

    Add `DEALEASY_API_KEY` and `DEALEASY_SHOP_DOMAIN` to your Oxygen environment variables, and to the `Env` type in `env.d.ts`.

## Caching instead of calling per view

On busy storefronts, you can call [List product campaigns](/campaigns/list-product-campaigns) every few minutes, cache the result, and match campaigns on each product view yourself. See [Matching campaigns yourself](/campaigns/list-product-campaigns#matching-campaigns-yourself).

## Apply code campaigns

When `method` is `CODE`, the discount only applies once the code is on the cart. You can add it with the Storefront API:

```graphql
mutation ApplyDiscount($cartId: ID!, $codes: [String!]!) {
  cartDiscountCodesUpdate(cartId: $cartId, discountCodes: $codes) {
    cart { id discountCodes { code applicable } }
    userErrors { field message }
  }
}
```

Pass `code` in `codes`. `applicable` becomes `true` once the cart quantity reaches a tier.

## Tips

- **Refetch when the variant changes** if the store has campaigns that target specific variants.
- **Send all collections.** Campaigns that target or exclude collections only match on the collection IDs you send. `collections(first: 250)` covers the 250-item limit of the request body.
- **Currency:** for `FIXED_AMOUNT`, the tier `value` is in the store currency. Convert it the same way you convert product prices when you show other currencies.
