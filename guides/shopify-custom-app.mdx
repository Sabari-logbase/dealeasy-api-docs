---
title: "Shopify custom app"
description: "Read Dealeasy campaigns from a custom Shopify app or backend service."
---

Use this guide when you have your own Shopify app or backend that needs a store's campaigns. For example:

- a theme app extension or app proxy that renders its own quantity selector or "Buy 1, get 1 free" badge
- a Checkout UI extension that shows "add 1 more to save 10%"

## Prerequisites

- An integration of type `SHOPIFY_CUSTOM_APP` with the `read_campaigns` scope, created by the merchant. See [Create an integration](/getting-started/create-an-integration).
- The key stored as a secret. If your app serves several stores, store **one key per store**, keyed by the `myshopify.com` domain.

## Steps

<Steps>
  <Step title="Store the key per store">
    Save each store's key as an encrypted secret, keyed by its `myshopify.com` domain.
  </Step>
  <Step title="Call Dealeasy from your backend">
    Send the key and the matching `x-shopify-domain` header. Use [Get campaigns for a specific product](/campaigns/get-campaigns-for-a-specific-product) for one product, or [Get all product campaigns](/campaigns/get-all-product-campaigns) to cache every campaign and match them yourself.
  </Step>
  <Step title="Expose only what your frontend needs">
    Return the campaign data from your own endpoint. For an app proxy, verify Shopify's proxy signature first.
  </Step>
</Steps>

## Backend example (Node.js + Express)

This endpoint is exposed to the storefront through a [Shopify app proxy](https://shopify.dev/docs/apps/build/online-store/app-proxies). It forwards the product and buyer to [Get campaigns for a specific product](/campaigns/get-campaigns-for-a-specific-product) and returns the campaigns that apply.

```javascript server/campaigns.js
import express from "express";

const DEALEASY_API_URL = "https://api.dealeasy.app/api/public/v1";

// Replace with your own encrypted secret storage.
async function getDealeasyKey(shop) {
  return process.env[`DEALEASY_API_KEY_${shop.replace(/\W/g, "_").toUpperCase()}`];
}

async function getProductCampaigns(shop, payload) {
  const apiKey = await getDealeasyKey(shop);
  if (!apiKey) throw new Error(`No Dealeasy integration configured for ${shop}`);

  const response = await fetch(`${DEALEASY_API_URL}/campaigns/products/search`, {
    method: "POST",
    headers: {
      "x-dealeasy-api-key": apiKey,
      "x-shopify-domain": shop,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(payload), // { productId, variantId, collections, tags, customer }
    signal: AbortSignal.timeout(5000),
  });
  const body = await response.json();
  if (!response.ok) {
    const error = new Error(body.message);
    error.code = body.code;
    error.status = response.status;
    throw error;
  }
  return body.campaigns;
}

const router = express.Router();
router.use(express.json());

// POST /apps/your-proxy/campaigns/search
// verifyAppProxySignature is your middleware that checks Shopify's app proxy HMAC.
router.post("/campaigns/search", verifyAppProxySignature, async (req, res) => {
  const shop = req.query.shop; // set by Shopify on app proxy requests
  const { productId, variantId, collections, tags, customer } = req.body;
  if (!productId) return res.status(400).json({ error: "productId is required" });

  try {
    const campaigns = await getProductCampaigns(shop, {
      productId,
      variantId,
      collections,
      tags,
      customer,
    });
    res.json({ campaigns });
  } catch (error) {
    console.error(`Dealeasy ${error.status ?? ""} ${error.code ?? error.message}`); // never log the key
    res.json({ campaigns: [] }); // degrade gracefully
  }
});

export default router;
```

<Tip>
  Shopify adds `logged_in_customer_id` to app proxy requests. For extra safety, use it as `customer.id` instead of the ID the browser sends.
</Tip>

## Call it from the theme

On a product page, your theme app extension already has every value the API needs in Liquid:

```liquid blocks/campaigns.liquid
<div id="dealeasy-campaigns"></div>
<script>
  (async () => {
    const payload = {
      productId: "{{ product.id }}",
      variantId: "{{ product.selected_or_first_available_variant.id }}",
      collections: {{ product.collections | map: 'id' | json }},
      tags: {{ product.tags | json }},
      {% if customer %}
      customer: {
        id: "{{ customer.id }}",
        isB2b: {{ customer.b2b? | json }},
        tags: {{ customer.tags | json }},
      },
      {% endif %}
    };

    const response = await fetch("/apps/your-proxy/campaigns/search", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(payload),
    });
    const { campaigns } = await response.json();
    for (const campaign of campaigns) {
      if (campaign.type === "VOLUME_DISCOUNT") {
        // render campaign.tiers as quantity tiers into #dealeasy-campaigns
      } else if (campaign.type === "BOGO_DISCOUNT") {
        // render "Buy {buyQuantity}, get {getQuantity} free" for each tier
      }
      // skip any other type
    }
  })();
</script>
```

If the buyer changes variant, call it again with the new variant ID.

## Test with cURL

Before wiring it into your app, check the key and domain from your terminal:

```bash
curl -X POST "https://api.dealeasy.app/api/public/v1/campaigns/products/search" \
  -H "x-dealeasy-api-key: $DEALEASY_API_KEY" \
  -H "x-shopify-domain: your-store.myshopify.com" \
  -H "Content-Type: application/json" \
  -d '{ "productId": "8012345678901", "variantId": "44012345678901", "collections": ["411234567890"], "tags": ["summer"] }'
```

A `200` response with `"campaigns": []` means the key works, but no campaign applies to that product and buyer. See [how a campaign is matched](/campaigns/overview#how-a-campaign-is-matched).

## Using the data

- **Volume discount nudges:** compare the cart quantity with `tiers` to show "Add 2 more to save 15%". Use `quantityScope` to decide whether to count per product, per variant, or across all products. See [Volume discount](/campaigns/volume-discount).
- **BOGO nudges:** use `buyQuantity` and `getQuantity` to show "Add 1 more to get it free". See [BOGO](/campaigns/bogo).
- **Stable references:** store the campaign `id`, not the tier `id`, because tier IDs are positional.
- **Code campaigns:** when `method` is `CODE`, show or apply `code`. `AUTOMATIC` campaigns need no action.

## Operational checklist

<AccordionGroup>
  <Accordion title="Key rotation">
    Create a new integration, deploy the new key, then revoke the old integration. See [Rotate or revoke a key](/getting-started/create-an-integration#rotate-or-revoke-a-key).
  </Accordion>
  <Accordion title="Merchant uninstalls Dealeasy or revokes the key">
    Requests return `UNAUTHORIZED`. Stop showing campaign messaging for that store and alert whoever manages the integration.
  </Accordion>
  <Accordion title="Rate limits">
    Cache responses and retry `TOO_MANY_REQUESTS` with exponential backoff. Don't call the API in a tight loop for every product. Fetch on demand and cache instead.
  </Accordion>
</AccordionGroup>
