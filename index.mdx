---
title: "Overview"
description: "Use the Dealeasy API to show a merchant's discount campaigns in your own storefront or app."
---

The Dealeasy API gives you read-only access to the **campaigns** a merchant runs with the Dealeasy Shopify app. Today that means **volume discounts**: tiered quantity discounts such as "Buy 3, save 10%". For any product and buyer, you can get the campaigns that apply and show them in your own UI.

Shopify still applies the discounts at checkout. The API tells you what to display. It doesn't change prices or carts.

## Who should use this API

<CardGroup cols={2}>
  <Card title="Headless storefronts" icon="window" href="/guides/shopify-headless">
    Hydrogen, Next.js, or any custom frontend that can't use the Dealeasy theme widgets.
  </Card>
  <Card title="Custom Shopify apps" icon="puzzle-piece" href="/guides/shopify-custom-app">
    Backends and custom apps that need a store's campaign data.
  </Card>
</CardGroup>

If the merchant uses a standard Online Store theme, the Dealeasy theme widgets already show these campaigns, so you don't need this API.

## How it works

<Steps>
  <Step title="The merchant creates an integration">
    In the Dealeasy admin, the merchant creates an integration and gets an API key. See [Create an integration](/getting-started/create-an-integration).
  </Step>
  <Step title="You call the API">
    Send the API key and the store's `myshopify.com` domain as headers. See [Authentication](/getting-started/authentication).
  </Step>
  <Step title="You render the campaigns">
    Send a product and the buyer to [Get specific product campaigns](/campaigns/get-specific-product-campaigns), and render the tiers you get back.
  </Step>
</Steps>

## Quick example

```bash
curl -X POST "https://api.dealeasy.app/api/public/v1/campaigns/products/search" \
  -H "x-dealeasy-api-key: $DEALEASY_API_KEY" \
  -H "x-shopify-domain: your-store.myshopify.com" \
  -H "Content-Type: application/json" \
  -d '{ "productId": "8012345678901", "variantId": "44012345678901", "collections": ["411234567890"], "tags": ["summer"] }'
```

```json
{
  "campaigns": [
    {
      "id": "gid://shopify/DiscountAutomaticNode/1234567890",
      "type": "VOLUME_DISCOUNT",
      "title": "Buy more, save more",
      "method": "AUTOMATIC",
      "code": null,
      "discountType": "PERCENTAGE",
      "quantityType": "RANGE",
      "quantityScope": "PER_PRODUCT",
      "appliesToSubscriptions": false,
      "combinesWith": { "productDiscounts": false, "orderDiscounts": true, "shippingDiscounts": true },
      "currencyCode": "USD",
      "startsAt": "2026-09-01T00:00:00Z",
      "endsAt": null,
      "tiers": [
        { "id": "tier-1", "quantity": 2, "value": 5, "isDefault": false },
        { "id": "tier-2", "quantity": 3, "value": 10, "isDefault": true }
      ]
    }
  ]
}
```

<Warning>
  The API key gives access to the merchant's discount data. Only use it on a server. Never put it in browser JavaScript, mobile apps, or public repositories.
</Warning>

## Endpoints

| Method | Path | Use it to |
| --- | --- | --- |
| `GET` | [`/campaigns/products`](/campaigns/list-product-campaigns) | List every active and scheduled product campaign with its rules. |
| `POST` | [`/campaigns/products/search`](/campaigns/get-specific-product-campaigns) | Get the active campaigns that apply to one product and buyer. |

## Base URL

```
https://api.dealeasy.app/api/public/v1
```

All requests use HTTPS, and every response is JSON.
