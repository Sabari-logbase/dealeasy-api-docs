Every error response has the same JSON shape:

```json
{
  "code": "INVALID_API_KEY",
  "message": "The API key is invalid for this store."
}
```

<ResponseField name="code" type="string" required>
  A stable, machine-readable code. Branch your code on this field.
</ResponseField>

<ResponseField name="message" type="string" required>
  A human-readable explanation for logs and debugging. Don't parse it, because the wording can change.
</ResponseField>

## Summary

| Code | HTTP | Retry? |
| --- | --- | --- |
| [`INVALID_REQUEST`](#invalid_request) | 400 | No. Fix the request. |
| [`MISSING_AUTHORIZATION_HEADER`](#missing_authorization_header) | 401 | No. Add the header. |
| [`INVALID_API_KEY`](#invalid_api_key) | 401 | No. Fix the key or the domain. |
| [`UNAUTHORIZED`](#unauthorized) | 401 | No. The merchant must fix the integration. |
| [`FORBIDDEN`](#forbidden) | 403 | No. The integration needs the scope. |
| [`TOO_MANY_REQUESTS`](#too_many_requests) | 429 | Yes, with backoff. |
| [`INTERNAL_SERVER_ERROR`](#internal_server_error) | 500 | Yes, with backoff. |

## INVALID_REQUEST

**HTTP 400.** A header, path parameter, query parameter or body field is malformed. Common causes:

- `productId` is missing from the body, or isn't a numeric ID or a `gid://shopify/Product/<id>` GID.
- `variantId`, a collection ID or `customer.id` isn't a numeric ID or a GID of the right type.
- `collections`, `tags` or `customer.tags` isn't an array of strings, or has more than 250 items.
- `customer.isB2b` isn't a boolean.
- The POST body isn't valid JSON, or `Content-Type` isn't `application/json`.
- `type` isn't a supported campaign type, or a query parameter is sent more than once.
- `x-shopify-domain` isn't a `*.myshopify.com` domain.
- The path or method isn't a supported endpoint.

```json
{ "code": "INVALID_REQUEST", "message": "customer.isB2b must be a boolean." }
```

**Fix:** read `message`, correct the parameter, and make sure the IDs come from the same store as `x-shopify-domain`.

## MISSING_AUTHORIZATION_HEADER

**HTTP 401.** `x-dealeasy-api-key`, `x-shopify-domain`, or both are missing or empty.

```json
{ "code": "MISSING_AUTHORIZATION_HEADER", "message": "Missing required header(s): x-dealeasy-api-key." }
```

**Fix:** send both headers on every request. Check that a proxy or framework isn't stripping custom headers, and that the environment variable holding the key is set in this environment.

## INVALID_API_KEY

**HTTP 401.** The API key is malformed or unknown, or it doesn't belong to the store in `x-shopify-domain`. All of these return the same error on purpose.

```json
{ "code": "INVALID_API_KEY", "message": "The API key is invalid for this store." }
```

**Fix:**
- Send the full key in the format `dealeasy_<integrationId>_<secret>`, with no `Bearer` prefix, quotes, or whitespace.
- Send the store's `myshopify.com` domain, not its custom domain, and make sure it is the store that created the integration.
- If the key may have been copied wrong, copy it again from the integration in Dealeasy. See [Create an integration](/getting-started/create-an-integration).

## UNAUTHORIZED

**HTTP 401.** The key is valid, but it can't be used: the integration has been deactivated or revoked, or Dealeasy is no longer installed on the store.

```json
{ "code": "UNAUTHORIZED", "message": "This integration is inactive or has been revoked." }
```

**Fix:** ask the merchant to check the integration's status in Dealeasy. A revoked key can't be reactivated. Use a key from a new integration.

## FORBIDDEN

**HTTP 403.** The integration is valid but doesn't have the scope this endpoint needs.

```json
{ "code": "FORBIDDEN", "message": "This integration does not have the read_campaigns scope." }
```

**Fix:** the merchant must create an integration that includes the scope named in `message`. For campaigns, that is `read_campaigns`.

## TOO_MANY_REQUESTS

**HTTP 429.** Too many requests for this store from your IP in a short period.

```json
{ "code": "TOO_MANY_REQUESTS", "message": "Too many requests. Please retry after a short delay." }
```

**Fix:** retry with exponential backoff, and cache responses on your server so you call the API less often. The `RateLimit-*` response headers show your remaining quota.

## INTERNAL_SERVER_ERROR

**HTTP 500.** Something went wrong on the Dealeasy side, for example a temporary problem reaching Shopify.

```json
{ "code": "INTERNAL_SERVER_ERROR", "message": "An unexpected error occurred. Please try again later." }
```

**Fix:** retry with exponential backoff. While it fails, show the product without campaign messaging instead of failing the page. If it keeps happening, contact Dealeasy support with the time of the request and the store domain. Never include your API key.

## Handling errors

```javascript
async function fetchCampaigns(url, options, attempt = 0) {
  const response = await fetch(url, options);
  const body = await response.json();
  if (response.ok) return body;

  const retryable = body.code === "TOO_MANY_REQUESTS" || body.code === "INTERNAL_SERVER_ERROR";
  if (retryable && attempt < 3) {
    await new Promise((resolve) => setTimeout(resolve, 2 ** attempt * 500));
    return fetchCampaigns(url, options, attempt + 1);
  }

  // Degrade gracefully: render the product without campaigns.
  console.error(`Dealeasy API ${response.status} ${body.code}: ${body.message}`);
  return { campaigns: [] };
}
```
